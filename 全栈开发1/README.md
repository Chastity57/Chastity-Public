#本代码用于用户注册及检验
1，运行方式：用户在登录界面输入对应数字以执行对应命令（1，注册  2，登录  3，退出程序）
//注：请在终端窗口下运行该代码！！！
2，项目结构：项目结构主要通过几个大函数模块实现
    1,主函数（main）显示清单指导用户操作       
    2，操作（loginact）通过switch命令将操作指引至对应操作模块
    3,哈希加密块（hashpass）
    4，注册（register）将用户信息录入切片userlist,并在register之前前置了checkname模块以保证用户的唯一性
    5，登录（login）通过遍历userlist找出用户名后嵌套密码对应模块，实现登录操作
